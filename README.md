# Sentiment Analysis Project

This project compares VADER (lexicon-based) and RoBERTa (deep learning) for sentiment analysis on Amazon Fine Food Reviews.

## Techniques used
- NLTK (VADER sentiment analysis)
- Hugging Face Transformers (RoBERTa)
- Data Visualization (Seaborn)

## Dataset
Amazon Fine Food Reviews (Kaggle)

## Dataset source:
https://www.kaggle.com/snap/amazon-fine-food-reviews

## Models
- VADER (rule-based)
- RoBERTa (pretrained transformer)

## Results
Comparison between classical NLP and deep learning models.
